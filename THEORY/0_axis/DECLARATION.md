# Soft Cognitive Cohesion — 이론 선언문 (DECL-2.0)

---

## 출발 질문

이 이론은 '사물이 존재한다'에서 시작하지 않는다. 그리고 — DECL-2.0 에서 — 이 이론은 '객체가 언제 출현하는가'에서 *끝나지도* 않는다.

이 이론이 풀려는 문제는 하나다:

> **왜 지능은 세계를 두 번 해석해야 하는가?**

현대 로봇 지능은 세계를 한 번 객체·레이블·토큰으로 해석한 뒤, 다시 행동 단위(affordance, contact, reachability, compliance)로 *재해석*한다. 두 해석은 결코 일치하지 않는다 — `perception 표상 ≠ action 표상`. 이 **이중 번역**이 깨지는 지점이 현대 perception-action 파이프라인의 구조적 결함이다.

이 이론의 답:

> **Perception 은 객체의 인식이 아니다. Perception 은 가능한 개입(intervention)의 장(field)을 형성하는 것이다.**

---

## 중심 주장 (DECL-2.0 축)

장면은 *개입 가능성 구조*에 대한 등급화된 참여 $u_t : X_t \to [0,1]$ 로 조직된다. 객체성·affordance·행동 단위·궤적·제어 모드·복구 행동은 원초가 아니다 — **하나의 장의 action-class별 *사영(projection)*이다.**

객체는 개입 가능성이 재사용 가능한, 해석-불변 단위로 안정화된 영역이다:

> **객체성 = 안정화된 affordance 구조.**

perception 이 만드는 단위가 곧 action 이 작용하는 단위다. 두 번째 번역은 없다.

```
감각 차이
  → u_t  (개입 가능성 장; 등급화된 참여)
  → 안정적 actional 응집
  → { 객체 · affordance · 행동단위 𝒜(u;Θ) · 제어모드 · 궤적 · (의미) }  ← 사영들
```

상세: [[CANONICAL_AXIS]] (spine) · [[PAI_GLOSSARY]] (어휘).

---

## Primitive

$$u_t : X_t \to [0,1]$$

이름 없는 연속 장. 값은 **참여 강도** — 어느 위치가 형성 중인 응집(궁극적으로 개입 가능) 구조에 얼마나 강하게 참여하는가. 클래스 소속 확률이 아니다. 레이블이 아니다.

현재 substrate 의 $u_t$ 는 *형태적(morphological)* 응집에 대한 참여다. 이를 *개입 가능성* 구조에 대한 참여로 만드는 것이 OP-ACTIONAL-U (사영-다발 우선; 새 $E_{\text{act}}$ 항은 사영이 불충분할 때만). 객체는 $u_t$ 의 에너지 최솟값 구조에서 사후 출현하는 *하나의 사영*이다.

## Substrate — DECL-1.0 의 질문 (보존)

DECL-1.0 의 출발 질문은 이제 이 이론의 **substrate 질문**이다 — 폐기가 아니라 *재배치*:

> **어떤 차이의 덩어리가 언제부터 하나의 객체가 되는가?** (substrate)

이 질문에 답하는 형태론(closure / separation / boundary / transport)과 102개 봉인 정리(CV-1.20), 그리고 여섯 인식론적 질문 Q1~Q6 는 모두 **불변**이다. 이들은 개입 장이 올라타는 *운반층(substrate)*이다 — 이론 자체가 아니라 이론의 토대.

### 중심 정리 — T8 (위상전이, substrate)

$$\frac{\beta}{\alpha} > \frac{4\lambda_2}{\lvert W''(c) \rvert}$$

성립하면 경계가 출현하고 객체성이 발생한다; 붕괴하면 장이 균일하게 융합된다. $\lambda_2$ 는 그래프의 해상도다. 멀리 있는 두 사과가 하나로 보이는 것은 오류가 아니라 그 해상도에서의 유효한 인식이다.

### 여섯 substrate 질문 Q1~Q6

| 질문 | 수학 구조 | 상태 | 사영 연결 |
|---|---|---|---|
| **Q1. 경계는 언제 출현하는가?** | T8 위상전이 | 대부분 Cat A | π_obj 의 토대 |
| **Q2. 여럿이 공존할 수 있는가?** | Multi-formation, Count bridge | Cat A (조건부) | π_obj 다중성 |
| **Q3. 어떻게 변하는가?** | Stochastic dynamics, Gibbs | Package I Cat A | π_time 의 토대 |
| **Q4. 몇으로 안정화되는가?** | K-selection | Cat B | perceived-K = action-context 의존 |
| **Q5. 시간이 지나도 같은 것인가?** | Temporal Identity, OT transport | Cat A (CV-1.13) | π_time 궤적 |
| **Q6. 분열·합병 후에도 이어지는가?** | σ-Inheritance | 진행 중 | 사영 불변성 |

### 에너지 구조 (substrate, 병합 금지)

$$E = \lambda_{\text{cl}} E_{\text{cl}} + \lambda_{\text{sep}} E_{\text{sep}} + \lambda_{\text{bd}} E_{\text{bd}} + \lambda_{\text{tr}} E_{\text{tr}}$$

네 항은 형태적(morphological)이다 — 형태의 자기 지지, 외부와의 대조, 전이 매끄러움, 시간 연속성. actional 항은 아직 없다 (사영 다발이 우선; OP-ACTIONAL-U).

## 가드레일 (non-overclaim — 구속력 있음)

1. DECL-2.0 은 perception-action 축을 **존재론적 중심**으로 승격한다 — *증명된 정리가 아니다*. 102개 substrate 정리는 봉인된 채 불변; 축 작업으로 claim 수는 움직이지 않는다.
2. $\mathcal{A}(u;\Theta)$, $\Delta_{\text{interp}}$, 불변성 기준은 **아직 정의되지 않았다** (OP-PAI-001..006, OP-ACTIONAL-U, OP-PROJECTION, OP-CONTROL-GROUNDING). Cat A/B 승격은 promotion pipeline 을 거친다.
3. Action ≠ motor output. Perception ≠ recognition/labeling. Affordance 는 사후 속성이 아니라 **구성적**이다.
4. 8개 기존 retraction 은 여전히 구속력 있음; 축은 이를 암묵적으로 부활시키지 않는다.
5. 이론은 상대주의가 아니다 — 구조화된 조건부성이다 ($N = f(\lambda_2, \beta/\alpha, m, \text{거리}, \text{해상도}, \Theta)$).

## 이 이론이 아닌 것

- 객체 검출 이론이 아니다. 클러스터링이 아니다. 퍼지 세그멘테이션이 아니다.
- VLA/RL 의 motor policy 가 아니다 — action 은 motor output 으로 환원되지 않는다.
- 공학적 vision-control 파이프라인이 아니다 — 그 파이프라인의 *이중 번역을 제거하는* 수학적 토대를 제공한다.
