# Canonical Axis — Actional Perception

This repository studies **one problem**: the structural interpretation gap between perception and action in embodied intelligence. A conventional pipeline interprets a scene once into objects/labels/tokens, then must *re-interpret* those into action-relevant structure (affordance, contact, reachability, compliance). Two interpretations, never reconciled: `perception representation ≠ action representation`.

## The thesis

> **Perception is the formation of a field of possible robot intervention.**
>
> A scene is organized as graded participation $u_t : X_t \to [0,1]$ in an emerging intervention-possibility structure. **Objecthood, affordances, action units, trajectories, control modes, and recovery behaviors are not primitives — they are action-class-specific *projections* of that one field.** An object is a region where intervention-possibility has stabilized into a reusable, interpretation-invariant unit: **objecthood is stabilized affordance structure.**

The unit perception produces *is* the unit action acts upon. There is no second translation.

## One field, many projections

```
sensory difference
   → u_t  (intervention-possibility field; graded participation)
   → stable actional cohesion
   → { π_obj   object individuation
       π_aff   affordance structure
       π_act   action units 𝒜(u; Θ)
       π_ctrl  control modes (impedance / compliance)
       π_time  trajectories / temporal intervention
       π_sem   semantic labels (downstream, out of core scope) }
```

The projections are *readouts of the same field*, each selected by an action class (manipulation, navigation, inspection, pushing, opening, insertion, compliance transition, recovery, human/object interaction). Action is **plural** and **not reducible to motor output**.
