# Scope Ledger — 무엇이 증명됐고 무엇이 방향인가

> [!important] 왜 이 문서가 있는가
> 이 저장소는 **점점 큰 주장을 쌓아왔지만 증명된 것은 가장 좁은 바닥층뿐**이다. `cold_failure_analysis_2026-05-20`가 이미 자백한다 — *"SCC는 proto-cohesive field morphology만 증명했는데, 산문은 마치 objecthood를 증명한 것처럼 말한다."* 이후 DECL-2.0(actional perception)과 UNIFIED_STRUCTURE(𝕌)가 그 위에 더 얹혔다. 이 문서는 그 기울기를 *가리지 않고 드러내는* 것이 진짜 조화라는 원칙 아래, 모든 주장을 3티어로 격리한다. **거시 산문은 자기 티어를 명시해야 한다.**

## 야망-증명 기울기 (한눈에)

```
증명됨       ┃ pre-objective field morphology (변분 위상)        ← 실제 결과, 제일 좁음
─────────────╂──────────────────────────────────────────────────
조건부       ┃ 특정 objecthood-인접 결과 (Cat B/C, 가설 하)
─────────────╂──────────────────────────────────────────────────
방향(OPEN)   ┃ objecthood 완성 → actional perception → 𝕌 단일화  ← 선언, 증명 0, 제일 넓음
```

야망은 위로 갈수록 커지고 증명은 아래에 몰려 있다. 이 비대칭을 *인정*하는 것이 본 ledger의 목적이다.

---

## TIER 1 — PROVEN (증명됨, sealed)

**실제로 확립된 것: 사전객체적 응집장의 변분 위상학(variational topology of pre-objective cohesion fields).** field morphology 이론. 71 Cat A (CV-1.20).

- **T8 위상전이** $\beta/\alpha > 4\lambda_2/|W''(c)|$ — 경계 출현 임계조건 (Q1).
- **T-Temporal-Identity 완전 Cat A** (CV-1.13) — 시간 동일성 (Q5); H-SINK 닫힘.
- **Package I 확률동역학** (T-PF-A1-AR/SDE/GI/PE) — Langevin/Gibbs (Q3).
- **Count bridge** $K_{\mathrm{bar}} = K_{\mathrm{act}}$ (조건부 resolved regime) (Q2/Q4).
- **σ-standard** + Lipschitz 인증서 (Q1/Q7).
- **L-CLOSURE-LIFT, L-UNI-ZMODE, L-SURFACE-TENSION-RESCALE** 등 형태론 보조정리.

**정직한 한 줄:** 여기까지가 "증명된 SCC"다. 이것은 *형태론*이지 아직 *객체론*도 *지각-행동론*도 아니다.

## TIER 2 — PARTIAL (조건부, Cat B/C)

**가설 하에서만 성립하는 objecthood-인접 결과들.** 20 Cat B + 6 Cat C.

- **K-selection** T-K-Select-PF / OBS — Cat B (H-T* 등 가설 하).
- **H-MORSE-Local** — Cat B (active-set 형식; Global Cat A는 OP-HMORSE-LOCAL-A).
- **σ-rich / T-σ-Theorem-4** — 워킹/Cat B (H-σ4 차단).
- **T-Persist-K-Sep/Weak** — H-SR/H-WS 조건부.
- **T-σ-Inherit (CONT/MERGE/SPLIT)** — Cat C 부분 (Wigner W9+).

**정직한 한 줄:** 이들은 "거의"지만, 명시된 가설이 무조건화되기 전까지 objecthood를 *완성*하지 못한다.

## TIER 3 — DIRECTION (선언, OPEN, 증명 0)

**산문이 말하지만 증명되지 않은 것.** 세 겹으로 쌓여 있다 — 위로 갈수록 넓고 더 미증명:

| 층 | 주장 | 차단 OP |
|---|---|---|
| **3a objecthood 완성** | "차이 덩어리가 객체가 된다" (DECL-1.0 산문) | OP-0005 (K-Select-DYN) · OP-0008 (merge/split) · OP-0021 (observer T_*) |
| **3b actional perception** | "perception = 개입의 장" (DECL-2.0) | OP-PAI-001..006 (전부 OPEN) |
| **3c 𝕌 단일화** | "모든 결 = 한 생성구조의 단면" ([[UNIFIED_STRUCTURE]]) | OP-UNIFY-1..3 · OP-PROLEGOMENA |

**정직한 한 줄:** 3a/3b/3c는 *연구 방향*이지 정리가 아니다. README 비-주장 ledger가 이미 이를 부정한다("objects are primitive — NO", "field-capacity selection solved — NO", "merge/split solved — NO").

## 가드레일 (구속력)

1. **티어 태그 의무.** objecthood / perception / action / 단일화를 *주장하는* 모든 거시 산문은 `[Tier 3 / DIRECTION]`을 달아야 한다. 증명된 것으로 읽히게 쓰지 말 것.
2. **바닥층 정직.** "SCC가 증명한 것"을 물으면 답은 **Tier 1 = field morphology**다. 그 이상은 조건부(2) 또는 방향(3).
3. **비계 금지.** Tier 3 위에 새 Tier 3를 더 쌓아 간극을 가리지 말 것. 새 방향은 *증명-부채를 줄일 때만* 가치가 있다 (macro_audit §9 hard-stop).
4. **substrate 불변.** Tier 1 (102 claims, CV-1.20)은 봉인. 본 ledger는 주장의 *눈금*이지 내용 변경이 아니다.
