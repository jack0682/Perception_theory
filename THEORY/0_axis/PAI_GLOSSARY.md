# PAI Glossary — Controlled Vocabulary

Canonical definitions for the perception-action axis. Where a term previously drifted (used inconsistently across DECLARATION / pivot / CV-1.15), the **canonical definition here governs**. See [[AUDIT_perception_action_2026-05-26]] §F for the drift analysis.

| Term | Canonical definition |
|---|---|
| **perception** | Formation of graded participation $u_t$ in an emerging intervention-possibility structure. Not recognition or labeling. |
| **object** | A region where intervention-possibility has stabilized into a reusable, interpretation-invariant unit. Derivative, not primitive. |
| **affordance** | The intervention-possibility content of the field at a site/region. **Prior to objects, not appended to them.** Objecthood = stabilized affordance structure. |
| **action** | Any admissible robot intervention — manipulation, navigation, inspection, pushing, opening, insertion, compliance transition, recovery, human/object interaction. **Not reducible to motor output.** |
| **control** | Realization of action-class projections under dynamic/embodiment constraints (impedance, compliance). The $\pi_{\text{ctrl}}$ projection. |
| **intervention** | A change an embodied agent can effect. The field $u_t$ ranges over intervention-possibility; it is *what perception is of*. |
| **participation field** | $u_t(x)$ = degree to which $x$ participates in a currently forming intervention-relevant cohesion. (Substrate `u_t` is participation in *morphological* cohesion; the axis target is participation in *intervention-possibility* — OP-ACTIONAL-U.) |
| **projection structure** | The bundle $\{\pi_{\text{obj}}, \pi_{\text{aff}}, \pi_{\text{act}}, \pi_{\text{ctrl}}, \pi_{\text{time}}, \pi_{\text{sem}}\}$ over one field. The central architectural claim. |
| **actional projection** $\mathcal{A}(u;\Theta)$ | Map from field to action-class-specific intervention structure, given embodiment parameter $\Theta$. OPEN (OP-PAI-002). |
| **semantic projection** $\pi_{\text{sem}}$ | Readout into symbolic/categorical units. Explicitly downstream; out of core scope. |
| **control projection** $\pi_{\text{ctrl}}$ | Readout into impedance/compliance/trajectory realization. OP-CONTROL-GROUNDING. |
| **temporal projection** $\pi_{\text{time}}$ | Field evolution read as action-conditioned trajectory. Substrate = OT transport / temporal identity (Q5). |
| **interpretation gap** $\Delta_{\text{interp}}(F)$ | Discrepancy between perceptual individuation and action interpretation of the same field. Components undefined — OP-PAI-001. |
| **translation gap** | The double-interpretation defect (`perception rep ≠ action rep`) the axis dissolves. |
| **embodiment constraint** $\Theta$ | Agent kinematics / reach / end-effector parameters constraining admissible interventions; enters $\mathcal{A}(u;\Theta)$. |
| **contact expectation** | Predicted contact set for a candidate intervention; a feature of $\pi_{\text{act}}$ in manipulation-class projections. |
| **compliance profile** | Stiffness/compliance schedule for realizing an intervention; a $\pi_{\text{ctrl}}$ attribute. |
| **substrate** | The sealed cohesion-field morphology (closure/separation/boundary/transport; 102 claims; Q1–Q6). The carrier, not the theory. |
