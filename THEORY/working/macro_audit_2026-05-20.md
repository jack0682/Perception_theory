# SCC Macro Audit — 2026-05-20

## 0. Purpose

This is a pause document, not a proof document.

The current risk is not that one more lemma is missing. The risk is that the theory has been moving by local proof pressure: proof for hypothesis, hypothesis for proof, patch for blocker, blocker for next seal. That mode can increase claim count while weakening the macro picture.

This audit answers five questions:

1. Where did the theory start?
2. Which claims are actually grounded?
3. Which claims are conditional but useful?
4. Which parts are still intuition, pressure, or extrapolation?
5. Where are the macro gaps now?

No canonical claim is promoted here. No theorem status changes here.

## 2. Origin: What The Theory Was Originally About

The theory started from one question:

> 어떤 차이의 덩어리가 언제부터 하나의 객체가 되는가?

The primitive move was:

$$
u_t : X_t \to [0,1]
$$

where $X_t$ is not a set of already individuated objects and $u_t(x)$ is not an object-membership probability. It is cohesion participation intensity.

So the original thesis was not:

> Given objects, describe their fields.

It was:

> Given relational sites and soft cohesion fields, explain when object-like units become legitimate readings of stable field patterns.

The original intellectual constraint was therefore strict:

> Do not smuggle objecthood, object count, identity, or labels into assumptions.

Everything after this is valid only to the extent that it respects that constraint.

## 3. What Is Actually Grounded

### 3.1 Field-first ontology

Grounded status: strong.

The theory has a stable primitive layer:

- relational graph / site substrate;
- fixed-mass field space;
- soft cohesion field;
- energy-based stabilization;
- objecthood as a posterior reading, not an input.

This is not merely rhetoric anymore. It is reflected in canonical state-space definitions and the single-field theorem ladder.

### 3.2 Q1 boundary / formation core

Grounded status: strongest part of the theory.

The T8 line is still the macro heart:

$$
\frac{\beta}{\alpha} > \frac{4\lambda_2}{\lvert W''(c) \rvert}
$$

The important content is not only the formula. It is the claim that object-like boundary emergence is condition-dependent, especially through resolution / graph spectrum.

Strongly grounded Q1 pieces include:

- T8 phase transition core;
- pre-objecthood formation;
- persistence-based morphology diagnostics;
- PersRidge boundary precision in phase-separated regime;
- several sigma / Hessian symmetry facts;
- recent uniform zero-mode and parameter-rescaling lemmas.

Main caveat: Q1 is strong under its mathematical framing, but the bridge from "boundary emerges in field energy" to "objecthood is fully explained" still needs an explicit macro theorem, not just accumulated local lemmas.

### 3.3 Count-language separation

Grounded status: strong and conceptually central.

The split

$$
K_{\mathrm{field}},\quad
K_{\mathrm{act}},\quad
K_{\mathrm{bar}},\quad
K_{\mathrm{soft}}
$$

is one of the theory's real achievements.

It blocks a major category error:

> model slots, active channels, topological components, and soft morphology count are not the same object count.

This is not a minor technicality. It is the theory protecting itself from object-first leakage.

### 3.4 Stochastic Package I

Grounded status: strong but not macro-complete.

The reflected Langevin / Gibbs / Poincare package gives real mathematical footing for dynamics on field polytopes.

But Package I does not give:

- Eyring-Kramers prefactors;
- natural derivation of $T_*$;
- dynamic K-selection;
- full metastable transition-rate theory.

So it is a foundation, not the completed dynamics story.

### 3.5 Temporal identity, stable regime

Grounded status: strong inside its assumptions.

T-Temporal-Identity reaching Cat A is important: stable component correspondence is no longer just metaphor.

But it does not yet solve:

- all K-jump cases;
- sigma inheritance through merge/split;
- Sinkhorn recomputation composition;
- global object identity across violent topology change.

## 5. What Is Still Intuition

### 5.1 "Objecthood" as a unified macro conclusion

The theory has many objecthood ingredients:

- boundary emergence;
- stable formations;
- persistence;
- count diagnostics;
- temporal correspondence;
- signatures;
- observer-dependent parameters.

But the single theorem that says "this package is enough for objecthood" is not yet explicit.

Current status:

> Objecthood is conceptually clear, locally formalized, but not yet packaged as one macro-level theorem with necessary and sufficient assumptions.

### 5.2 $K$ as perceived object number

The count split is rigorous. The interpretation "this is the perceived number of objects" is still macro-intuitive unless the observer/readout layer is fixed.

Danger:

> Treating $K_{\mathrm{bar}}$ or $K_{\mathrm{act}}$ as the object count without specifying observation regime.

### 5.3 $T_*$ / observer-personal temperature

CV-1.18 cleaned the ontology by accepting Route C and deprecating Routes A/B. That is useful.

But Route C is still largely an axiomatic registration and resident parameter strategy, not a fully derived mechanism.

So the intuition is:

> effective perceptual temperature exists as an observer-conditioned parameter.

The remaining mathematical demand is:

> fixed-point existence, multiplicity, and operational measurability.

### 5.4 Sigma as identity carrier

Sigma-rich fingerprints feel like the right language for "same structure through change."

But merge/split remains exactly where identity is hardest. The theory should not pretend sigma-inheritance is solved while OP-0008-MERGE/SPLIT are Cat C.

## 6. What Looks Forced Or Overextended

### 6.1 Proof-count pressure

Recent sessions show a pattern:

> critique about insufficient proof -> immediate proof-first seal -> higher claim count.

This can be productive, but it also risks selecting lemmas because they are sealable, not because they close the central gap.

CV-1.20 is mathematically useful, but it does not by itself solve K-selection, sigma inheritance, or macro objecthood.

### 6.2 Technical H-MORSE expansion as substitute for macro closure

H-MORSE work is important for Package II and Kramers theory.

But if the project spends too long improving local Hessian / zero-mode structure, it may drift away from the original objecthood question unless each lemma is tied back to one of:

- boundary emergence;
- persistence of object-like unit;
- transition / merge / split;
- count selection;
- observer readout.

### 6.3 Treating Cat B chains as de facto Cat A

The danger zone is any chain of the form:

> Cat B theorem + plausible condition + numerical anchor + narrative necessity = macro conclusion.

That is not a proof. It is a research program.

### 6.4 Navigation layer drift

If top-level MOCs say CV-1.16 while canonical registries say CV-1.20, the theory loses a single shared present tense.

That makes it easier to accidentally cite old blockers as current or current fixes as globally settled.

## 8. Current Macro Gaps

### Gap A — The objecthood theorem is not yet explicit

Need a theorem-form statement:

> Under assumptions A, a stabilized SCC field gives an object candidate with properties B, C, D; under failure of assumptions, objecthood reading degrades in specified ways.

Without this, the theory has many components but no macro closure point.

### Gap B — Observer/readout layer remains under-axiomatized

The theory says object count, boundary, and identity depend on observation conditions. That is right.

But the observer parameter package needs a compact macro statement:

- what is fixed by graph/sensor geometry;
- what is inferred;
- what is observer-personal;
- what is not identifiable.

### Gap C — K-selection is still not closed

Q4 remains a central debt.

Current state:

- EQ and OBS routes are Cat B;
- DYN route is open;
- $T_*$ and Package II remain the main blockers.

This means:

> The theory can often say how to read K in a regime; it cannot yet fully explain why the system chooses that K dynamically.

### Gap D — Merge/split identity is not solved

Q5 stable temporal identity is strong. Q6 is not.

The hardest objecthood cases are exactly:

- two formations become one;
- one formation becomes two;
- identity survives or fails through topological event.

OP-0008-MERGE/SPLIT remains a macro blocker, not a side issue.

### Gap E — Conditionality ledger is scattered

The conditions are mostly recorded, but not in one human-readable macro ledger.

Need a table that says, for every major narrative sentence, exactly which assumptions support it.

Example:

| Narrative sentence | Minimal support | Current confidence |
|---|---|---|
| Boundaries emerge by field instability | T8 core + graph spectrum | high |
| Multiple objects can coexist | Q2 resolved-regime results | medium-high, conditional |
| The perceived count is selected dynamically | K-selection DYN + Package II + $T_*$ | low-medium, open |
| Identity survives through merge/split | Temporal identity + sigma inheritance | medium for stable cases; low for MERGE/SPLIT |

## 9. Hard Stop Rules For Next Work

Until this audit is resolved, new proof work should pass these gates:

1. Which macro question Q1-Q6 does this close?
2. Does it reduce a current blocker, or just add a nearby lemma?
3. Is the result Cat A, Cat B, Cat C, or only intuition?
4. What exact sentence in the big-picture theory becomes more justified?
5. What sentence must remain a non-claim?

If a proposed proof cannot answer these, pause it.
