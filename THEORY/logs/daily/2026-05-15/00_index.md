## 진행 규약 (자기 강제)

1. **새 어휘 생성 금지.** 새 약어, 새 framework letter (P1/P2/P3 같은 것), 새 acronym 금지. 통찰을 *기존 canonical 어휘* 만으로 검토.
2. **archive 재포장 금지.** V-AFD/R-2 의 어떤 부분도 "사실은 옳았다" 식으로 *후행 정합화* 시도 금지. 정직히 *왜 archive 됐는지* 만 본다.
3. **canonical 인용 강제.** 각 단계에서 "현재 canonical 의 ____ 가 이 부분에 해당" 형태로 *구체 위치* (파일명 + 절번호 + 정리/정의 이름) 명시.
4. **검증 질문이 결정 게이트.** *"canonical 에 없는 구체 수학 명제가 떠오르는가?"* — 떠오르지 않으면 결정 C 후보, 떠오르면 그 명제를 *적은 채로* A 또는 B 판별.
5. **결론 강제 안 함.** C (철학 완결) 결론도 *정당한* 결과. "추가 작업 없음" 이 인정될 수 있음.
