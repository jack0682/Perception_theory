## §5. Five Anti-Patterns (Day 3 Explicit Enumeration)

**(AP1)** Stage 2 cluster critic dispatch (heavy external agent dispatch for all 49 parking-lot files) not before W7 D6. Rationale: Stage 1 (per-file Cat-status headers, ~25-30 files, ~8-12h) must precede Stage 2 for structured critic inputs.

**(AP2)** No additional parking-lot inventory stages (Stage 3+) added before W7 D1-D3 Stage 1 completion. Rationale: inventory proliferation is W4 debt pattern; Stage 0 is done; Stage 1 is the load-bearing next step.

**(AP3)** New Issue series (#6, #7, ...) audits are lower priority than substantive theorem creation. W7-W10 issues audits only if surfaced by Stage 1 actual editing (not speculative).

**(AP4)** "Calendar itself is substantive progress" prevention. W7-W10 calendar (G3.12) is a reference tool, not a deliverable. Day 3 EOD evaluation: "did G3.2 produce a reproducible worked example?" — not "did we produce a calendar?".

**(AP5)** "Proposal-pattern for everything" prevention. Stage 1 per-file edits, OP-0009-Pre actual mathematical work, P-F framework axiom proof — all require direct working/canonical edits, not only daily-log proposals. W7 D2+ may require working/ direct edits (authorized by user).
